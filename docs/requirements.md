1. El sistema deberá permitir al cajero registrar una nueva orden de venta.
2. El sistema deberá permitir registrar el nombre del cliente asociado a cada orden.
3. Cuando el cajero agregue un producto a una orden, el sistema deberá permitir seleccionar la cantidad solicitada.
4. Cuando un producto disponga de diferentes tamaños, el sistema deberá permitir seleccionar uno de los tamaños disponibles.
5. Cuando un producto disponga de toppings o complementos, el sistema deberá permitir seleccionar uno o más de los disponibles.
6. El sistema deberá permitir registrar indicaciones especiales para los productos agregados a una orden que admitan esta opción; las bebidas no deberán mostrarla.
7. Cuando el cajero agregue, modifique o elimine un producto o una personalización de la orden, el sistema deberá actualizar el total de la venta.
8. Mientras una orden no haya sido cobrada, el sistema deberá permitir al cajero modificar los productos, cantidades, personalizaciones e indicaciones especiales registrados.
9. Mientras una orden no haya sido cobrada, el sistema deberá permitir al cajero eliminar productos registrados en la orden.
10. Cuando el cajero confirme una orden, el sistema deberá generar una comanda que incluya los productos solicitados, sus cantidades, personalizaciones e indicaciones especiales.
11. Cuando se genere una comanda, el sistema deberá asociarla con un identificador único de la orden.
12. Cuando el cajero proceda al cobro de una orden, el sistema deberá mostrar el total correspondiente a la venta.
13. Cuando el cajero proceda al cobro de una orden, el sistema deberá permitir seleccionar efectivo o transferencia como método de pago.
14. Cuando el cajero confirme el pago de una orden, el sistema deberá registrar el importe total, el método de pago y la fecha y hora de la venta.
15. Cuando el pago de una orden sea confirmado, el sistema deberá marcar la orden como cerrada.
16. Cuando una orden haya sido cerrada, el sistema no deberá permitir agregar, modificar o eliminar productos de la orden.
17. Cuando se cierre una orden, el sistema deberá generar un ticket que incluya el nombre del cliente, los productos solicitados, el total de la venta y el método de pago.
18. Cuando se genere un ticket, el sistema deberá permitir al cajero imprimirlo.
19. Cuando el cajero cancele una orden antes de confirmar su pago, el sistema deberá marcar la orden como cancelada.
20. Cuando una orden sea cancelada, el sistema deberá excluirla de los totales de ventas y del corte de caja.
21. El sistema deberá almacenar las ventas realizadas durante la jornada.
22. Cuando el cajero solicite realizar el corte de caja, el sistema deberá calcular el total de ventas realizadas durante la jornada.
23. Cuando el cajero solicite realizar el corte de caja, el sistema deberá calcular por separado el total de ventas pagadas en efectivo y el total de ventas pagadas mediante transferencia.
24. Cuando se realice el corte de caja, el sistema deberá permitir al cajero registrar el monto de efectivo contado físicamente.
25. Cuando el cajero registre el monto de efectivo contado, el sistema deberá calcular la diferencia entre el efectivo esperado según las ventas y el efectivo contado.
26. Cuando finalice el cálculo del corte de caja, el sistema deberá mostrar el total vendido, el total recibido en efectivo, el total recibido mediante transferencia, el efectivo contado y la diferencia de caja.
27. El sistema deberá solicitar al usuario seleccionar su nombre e ingresar un PIN de 4 dígitos para iniciar sesión.
28. Mientras el usuario tenga el rol de encargado, el sistema deberá permitirle agregar personas con su nombre, PIN y rol, y quitarles el acceso.
29. Mientras el usuario tenga el rol de cajero, el sistema no deberá permitirle administrar al equipo.
30. Cuando un producto tenga opciones obligatorias, el sistema no deberá permitir agregarlo a la orden hasta que se seleccionen.
31. Mientras la orden no tenga productos o nombre de cliente, el sistema no deberá permitir confirmarla.
32. Cuando el cajero modifique una orden confirmada, el sistema deberá solicitar confirmarla de nuevo para actualizar la comanda.
33. Cuando el método de pago sea efectivo, el sistema deberá calcular el cambio a partir del monto recibido.
34. Cuando el método de pago sea transferencia, el sistema deberá generar un concepto único y permitir enviarlo al cliente por WhatsApp.
35. Cuando se confirme una orden, el sistema deberá mostrarla en la lista de órdenes en preparación.
36. El sistema deberá permitir marcar los productos de una orden como preparados y la orden como entregada.
37. Cuando se calcule el efectivo esperado, el sistema deberá incluir el fondo de caja.
38. Cuando el cajero cierre el turno, el sistema deberá imprimir el corte de caja.
